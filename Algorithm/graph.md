# 그래프

- 정점(Vertex, 노드)와 이를 연결하는 간선(Edge)으로 이루어진 자료구조, 데이터 간의 관계를 표현하는데 주로 사용된다.
- 트리, 배열, 리스트보다 더 넓은 범위를 표현하는 비선형 자료구조다.
- 그래프는 인접 리스트(각 정점별 연결 리스트)나 인접 행렬(정점간 연결 여부를 2차원 배열로 표현)로 구현할 수 있다.


>
> ::🧞‍♂️ 그래프 실생활 실무 에제
> 
> 1. 소셜 네트워크 친구 관계 분석
> - 사용자는 정점, 친구 관계는 간선으로 표현하여 친구 추천이나 탐색 등에 사용
> - 그 외, 상품 추천 시스템
>
> 2. 네트워크 라우팅(인터넷 라우터, 네트워크 최단경로)
> - 컴퓨터, 라우터가 정점, 네트워크 연결(케이블 등)이 간선
> - 데이터 전송 최적 경로(최단 경로 알고리즘, 다익스트라) 찾기
>
> 3. 기타 실무
> - 그래프 탐색 (DFS, BFS), 최단 경로, 최소 신장 트리 등에서 사용
>

## 그래프를 활용한 대표적인 알고리즘

### DFS (Depth First Search)

- 깊이 우선 탐색 알고리즘으로, 루트 노트에서 시작해서 인접한 노드 중 하나를 정하고 가능한 가장 깊게 탐색 탐색한 후 더 탐색할 노드가 없으면 되돌아가서 다른 경로를 탐색하는 과정을 반복하는 방식이다.
- DFS 를 구현할 땐, 주로 스택(FIFO)이나 재귀함수를 활용하는데 재귀로 구현 시 데이터 수가 커졌을 경우 `RecursionError` 등의 에러 발생 가능성이 있어 안전하게 스택을 활용하는 것이 대표적이다. (구현은 `dfs.py` 참고)

>
> ::🧞‍♂️ DFS 실생활 실무 에제
> 
> - 미로 찾기, 퍼즐 풀이 등에서 목적지까지 가는 모든 경로 또는 가능한 해답 전체를 구할 때 주로 사용된다.
> - 컴파일러의 구문 트리 분석, 웹 크롤러의 웹 사이트 전체 링크 순회 등에서 활용되는 등 "모든 가능성, 깊이 들어가는 탐색, 계층적 구조 순회"가 핵심이다.
